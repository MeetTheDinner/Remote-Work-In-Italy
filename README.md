# Remote-Work-In-Italy
This repository includes the files used in coding for the undergraduate capstone project at John Cabot University.

This is the readme file for the Italian Rental Affordability Capstone Project & Code. All primary files have been included including the capstone project, the dataset as a csv file, the dataset as an Excel file, & some Jypter notebooks needed for the code. These can be viewed in Microsoft Visual Studio Code.

Not all sub datasets used for the completion of the primary dataset were included due to the file limitation number being capped at 20 files. Should you wish to use these files, they are included in the zip folder labelled Data.

Additionally, more code and data was used outside of the file contents to extract data from the ISTAT's Labour Force Survey. They have not been included due to the boated file size of the contents, even in a zipped format. Should you wish to view these files as well, please contact me at christopher.newell@johncabot.edu.
